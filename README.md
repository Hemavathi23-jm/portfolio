* **GitHub Profile & Repos:** [Hemavathi23-jm](https://github.com/Hemavathi23-jm)
* **Highlights:**
  - **Zero Double-Booking Guarantee:** Collision-free scheduling engine checking physician shift bounds, lunch hours, and approved leave calendars.

  - **Weighted Dynamic Triage Algorithm:** Prioritizes active patients (`EMERGENCY [100]` > `SENIOR CITIZEN [50]` > `SCHEDULED [10]` > `WALK_IN [5]`).
